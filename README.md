# DueDash

DueDash is a simple student productivity web app designed to help users keep track of upcoming exams, assignments, and projects in one place. The project is built with plain HTML, CSS, and JavaScript and runs entirely in the browser.

## Overview

DueDash provides a clean dashboard where students can:
- View upcoming assessments by category
- Add new exams, assignments, and projects
- Organize items by priority
- Delete items from the dashboard
- Use a built-in study timer for focused sessions

## Features

- Dashboard home page with separate sections for exams, assignments, and projects
- Add Assessment form for creating new entries
- Priority-based visual labels such as Low, Medium, and High
- Persistent local storage so entries remain available in the browser
- Study timer page with multiple study methods
- About Us and Sign In pages for navigation

## Project Structure

- Home.html — main dashboard page
- Assignment.html — assignment-related page
- Exam.html — exam-related page
- Project.html — project-related page
- Add_Assessment.html — form for adding new tasks
- StudyTimer.html — study timer experience
- css/ — stylesheets
- js/ — JavaScript logic for the dashboard and timer
- Icons/ — images and icons used across the site

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage for data persistence

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your browser.
3. Launch the main page by opening Home.html.

You can also use a live server extension in VS Code for a smoother local preview.

## Usage

- Open Home.html to see your dashboard.
- Click the Add Assessment button to create a new exam, assignment, or project.
- Use the Study Timer page to start a study session with a chosen method.
- Items added to the dashboard are stored locally in your browser.

## Notes

- This project is front-end only and does not use a database or backend server.
- Data is saved using browser local storage, so clearing browser storage will remove saved items.
